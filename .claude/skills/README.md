# Skills

These two Claude Code skills come from the [Prog8 project](https://github.com/irmen/prog8) (`.agents/skills/` at tag `v12.3.4`), written by Prog8's author, Irmen de Jong. They are licensed under the **GNU GPL 3.0**, like Prog8 itself, not under this repository's MIT license.

- `prog8-coder/`: Prog8 language rules
- `asm6502-coder/`: 6502 assembly in 64tass syntax, for inline assembly in Prog8
